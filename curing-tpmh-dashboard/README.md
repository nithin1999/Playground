Project dashboard for the Curing TPMH / 2-operator staffing improvement project.

## Latest improvement — Break-Relief Handoff Standard
Break relief is now treated as a **planned role substitution**, not informal help. In a true 2-operator design, when one operator leaves for a break the process must still retain two qualified zone owners or explicitly enter an approved reduced-coverage/containment condition. A relief person only counts as usable capacity when that person is qualified for the assigned zone and has actually accepted ownership of the current abnormal/recovery queue.

Before release to break, use a short handoff: **Zone/press ownership → active abnormalities → NEW/OWNED/WAITING work → protected routine work due during break → known equipment constraints → relief accepts ownership → operator released**. On return, reverse the handoff and close/reassign anything still open. Record planned vs actual break start/end, relief person, handoff time, delayed/interrupted relief, and any work displaced from the relief person's home role.

This closes a major hidden-labor risk: Mold/Bladder/Team Lead coverage cannot be treated as free capacity. Their own due work remains demand, and any incremental carryover/support people-minutes must be measured. No universal break duration, delay limit, or staffing threshold is invented; use plant requirements and baseline evidence.

## Best current strategy
1. Map travel; remove avoidable motion; balance zones on workload + peaks + travel.
2. Freeze NORMAL routes and ABNORMAL dispatch with one owner per event.
3. Use the visible NEW → OWNED → WAITING/ESCALATED → RECOVERED queue; displaced work remains demand until recovered.
4. Verify demonstrated skill coverage for the actual Op1/Op2/relief pairing; close critical gaps with TWI-style instruction/verification.
5. Treat breaks as a planned staffing transition using the **Break-Relief Handoff Standard**; relief must accept zone + queue ownership before release.
6. Retain the relief person's own due work and measure any incremental carryover/support burden rather than hiding transferred labor.
7. Build qualification-constrained 30-minute Capacity Reserve + Recovery Profiles, including break windows.
8. Freeze measurement definitions, SIC/leader checks, Green/Amber/Red authority and CONTAIN → STABILIZE → RECORD → RESTART logic.
9. Add time-on-shift and actual relief timing to the Pilot Context Card and observation sheet.
10. Collect a context-characterized 3-op baseline using identical definitions, including normal outside-support people-minutes, relief handoffs and time-on-shift behavior.
11. Shadow 2-op; capture periodic confirmations plus consequential exceptions, queue/recovery, support people-minutes, containment and actual breaks.
12. Calculate scheduled TPMH, Effective Labor Hours, Support Burden and Adjusted TPMH.
13. Compare context-matched 3-op/2-op periods; Pareto incremental support, structural overload, duplicate response, backlog, motion, skill, containment, relief and recovery exceptions.
14. Redesign, then expand across underrepresented demand, downtime, break, late-shift and A/B/C/D crew conditions.
15. Move to true 2-op only after representative conditions pass without hidden labor transfer, recurring overload, protected-work failure, missed relief, persistent backlog, duplicate dispatch or qualification-dependent intervention.

## Pilot gates
- Gate 0 — Data/design: layout, alarm evidence, travel study and candidate zones.
- Gate 1 — Standard work/skills: NORMAL route, ABNORMAL ownership/dispatch/recovery, response matrix, visible queue and demonstrated critical-task coverage.
- Gate 2 — Relief/capacity: qualified relief reservation, Break-Relief Handoff Standard, relief-home-work accounting, plus preliminary 30-minute Capacity Reserve + Recovery Profile.
- Gate 3 — Management/measurement: measurement dictionary, observer check, leader standard work, visual controls, intervention taxonomy, escalation and containment/restart authority.
- Gate 4 — Baseline/context: 3-op state measured with identical definitions, including time-on-shift and actual break/relief handoffs.
- Gate 5 — Shadow 2-op: capture context, time on shift, exceptions, queue/recovery, support labor, breaks and containment/restart episodes.
- Gate 6 — Matched analysis/revise: compare context-matched exposures using scheduled/effective labor and time-on-shift stratification.
- Gate 7 — Coverage: deliberately cover underrepresented demand, concurrency, break, late-shift, downtime/recovery and crew conditions.
- Gate 8 — True 2-op/control: demonstrated acceptance across representative conditions with controlled standard work, skills, relief, dispatch, escalation, SIC and control plan.
