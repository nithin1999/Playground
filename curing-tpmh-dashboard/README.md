## Latest improvement — Event-Driven Dispatch Priority Ladder
PRIMARY/FLEX ownership answers who owns work, but not what an operator should do first when several valid demands compete. In a machine-intensive process, that ambiguity can create avoidable walking, task switching, duplicate response, or silent deferral of protected work. Before the pilot, define one plant-approved dispatch ladder that both operators use whenever competing demands exist.

Use this framework without inventing plant thresholds: (1) plant safety / quality / equipment-protection containment always overrides; (2) then any plant-defined time-critical abnormal response; (3) then due protected/periodic work according to its real due requirement; (4) then normal owned work / route; (5) then discretionary noncritical work. Within the same priority level, stay with PRIMARY ownership unless the defined FLEX trigger is met. If plant rules require a different order, plant rules win.

For every meaningful reprioritization, capture: time | competing demands | selected demand | governing priority/reason | deferred work | FLEX invoked? | deferred-work recovery time | consequence. This allows Thursday to distinguish a true two-operator capacity shortage from poor sequencing/dispatch.

Do not invent response-time or lateness limits. Use actual plant-authorized rules, protected-work due requirements and Thursday observations.

## Risks / gaps
- No verified Thursday 2-operator performance exists yet.
- Exact plant-authorized containment/restart criteria and authority have not been supplied here.
- Alarm concurrency is a demand proxy, not operator work interference.
- PRIMARY/FLEX ownership alone does not resolve which competing task should be done first.
- Unclear dispatch priority can create unnecessary task switching, walking, duplicate response or silent protected-work deferral and falsely resemble insufficient staffing.
- Excessive cross-zone flex can hide an unbalanced route even if shift-average workload looks acceptable.
- No saturation on a low-demand Thursday would be under-exposure, not proof of staffing adequacy.
- A single shift can leave important demand-state combinations untested even if average TPMH looks good.
- Shift-average TPMH can hide late-shift deterioration or break-relief fragility.
- Hidden support can falsely validate staffing if donor-role displacement is not followed.
- Protected/periodic work can be silently deferred during alarms unless due work is visible.
- Relief/flex coverage is not proven until required qualifications are verified.
- Prior idle-time observations are not removable labor until base work, walking, machine-auto time and abnormal reserve are separated.
