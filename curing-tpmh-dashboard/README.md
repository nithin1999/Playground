## Latest improvement — Relief Coverage Feasibility Matrix
The 2-operator design must prove not only that total operator-minutes are sufficient, but that the **right qualified capacity exists at the right time** when an operator is on break, responding to an abnormality, or otherwise unavailable. A pooled capacity number can look healthy while the crew is operationally uncovered because the remaining person or relief source cannot perform a required task.

Before shadow 2-op, build a time-phased matrix with rows for critical Curing work/abnormal tasks and columns for Op1, Op2, proposed relief sources, leader/shadow and relevant shared-support roles. For each cell record demonstrated qualification/authorization and any restrictions. Then overlay planned break windows and observed abnormal-response demand.

For every planned break/relief window verify:
1. Who owns Op1 and Op2 normal/protected work?
2. Who can respond to each critical abnormal task if the active operator is already committed?
3. Which tasks require two people or external/shared support?
4. What happens to the relief person's home-role work while covering Curing?
5. Is any required task left with a single qualified person or no qualified coverage?

Classify uncovered conditions as a **coverage gap** and redesign the break timing, zone ownership, cross-training or backup rule before using the window as evidence of true 2-op feasibility. Do not invent a numerical redundancy target; use plant safety/quality/authorization requirements and demonstrated qualification. Keep relief home-role recovery labor visible in Effective Labor so coverage is not achieved by exporting hidden workload.
