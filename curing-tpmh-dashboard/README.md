# Curing TPMH Dashboard

Project dashboard for the Curing TPMH / 2-operator staffing improvement project.

## Current status
Design/validation phase. No 2-operator pilot success or permanent manpower reduction is claimed. Tricycle remains closed after Safety rejection.

## Latest improvement — Exposure-Matched Pilot Comparison Gate
A shift-to-shift TPMH comparison can give a false answer if the 3-operator baseline and shadow 2-operator exposure do not face comparable operating opportunity. Running presses, press-hours/cycles, product/mix, gantry or press downtime, manual-support conditions, break exposure and abnormal-event demand can all change independently of staffing.

Before comparing staffing conditions, characterize every observation window with an **Exposure Signature**: running press-hours/cycles, scheduled/actual production opportunity, product/mix where available, major press/gantry downtime, alarm/event count and observed hands-on abnormal demand, break/relief exposure, staffing/qualification state, and material special conditions.

Use matched blocks where practical: compare 3-op baseline and shadow 2-op windows with similar exposure signatures, or stratify results by the nuisance factor rather than pooling unlike windows. Do not discard difficult 2-op windows merely to obtain a match; retain them as stress-condition evidence. Do not claim equivalence from a small number of matched windows.

Primary comparison remains multi-dimensional: scheduled TPMH, Effective Labor Hours, Support Burden, Adjusted TPMH, operator-minute reserve, saturation/collisions, protected-work completion, break/relief performance, recovery/backlog, coaching/rescue demand, safety/quality outcomes and abnormal-response performance.

## Best current strategy
1. Map recurring work and travel; remove avoidable motion and point-of-use gaps.
2. Demand-weight Op1/Op2 zones by work content + travel + abnormal exposure, not equal press count.
3. Build the Operator-Minute Capacity Envelope by interval so nominal headcount is separated from usable reserve.
4. Preserve fixed-window variability and test Cross-Zone Collision/shared-resource exposure.
5. Build the task-by-person skill matrix and apply the Demonstrated Skill-Readiness Gate; count independent capacity only where demonstrated.
6. Build the time-phased Relief Coverage Feasibility Matrix across Op1, Op2, relief, leader/shadow and shared support.
7. Freeze NORMAL routes and single-owner ABNORMAL dispatch.
8. Use Live Abnormality Ownership Board with explicit event states.
9. Use NORMAL → CONSTRAINED → SATURATED → RECOVERY workload states.
10. Protect due work with a plant-approved Protected Work Matrix and Due-Time Recovery Queue.
11. Close critical single-point skill gaps using TWI-style job breakdown, coached practice and independent demonstration.
12. Treat breaks as staffing transitions with demonstrated independent relief capability; quantify Break-Relief Debt and relief home-role recovery labor.
13. Use Pilot Leader Standard Work and sample Process Confirmation on critical behaviors.
14. Run the Pre-Pilot Scenario Challenge including skill-gap, relief-home-role, coverage-gap and SATURATED-state scenarios.
15. Freeze measurement, escalation and CONTAIN → STABILIZE → RECORD → RESTART definitions.
16. Apply the Pre-Exposure Readiness Gate and log material change points.
17. Collect context-characterized 3-op baseline using the Interval Capacity-Loss / Recovery Board and capacity ledger.
18. Build an Exposure Signature for each baseline/shadow window and predefine matching/stratification fields before reviewing staffing results.
19. Run controlled shadow 2-op with a qualified third operator as rescue capacity only; log every coaching/rescue intervention.
20. Compare exposure-matched or exposure-stratified 3-op vs shadow 2-op windows; retain unmatched stress windows separately rather than hiding them.
21. Calculate scheduled TPMH, Effective Labor Hours, Support Burden and Adjusted TPMH including production assistance, coaching, relief and recovery labor.
22. Compare stable-condition segments for operator-minute reserve, workload-state transitions, collisions, skill/coverage gaps, response, work-at-risk, relief debt, adherence, intervention demand and capacity loss.
23. Apply the Time-of-Shift Robustness Gate: stratify the same evidence by hours since shift start and look for recurring late-shift deterioration without inventing thresholds.
24. Pareto exceptions and redesign.
25. Repeat shadow exposure across demand, downtime, break, late-shift and A/B/C/D conditions before true 2-op.
26. Move to true 2-op only after representative evidence shows operation without hidden third-person labor/coaching, recurring reserve depletion/saturation/collision failure, skill/coverage gaps, protected-work failure, missed relief, persistent relief debt/backlog, dispatch ambiguity, late-shift deterioration, or an impractical standard-work method.

## Immediate next action
Before the next baseline/shadow comparison, create a one-row **Exposure Signature** for every observation window: shift/crew, start/end, running press-hours or cycles, planned/actual output opportunity, product/mix, major downtime, abnormal events plus observed hands-on demand, break/relief exposure, actual staffing/qualifications, and special conditions. Predefine which fields make windows reasonably comparable; where matching is not possible, stratify rather than pool. Preserve high-stress unmatched 2-op windows as robustness evidence.
