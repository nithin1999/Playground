## Latest improvement — treat break relief as reserved capacity, not borrowed labor
A 2-operator design can appear feasible at average staffing yet fail during breaks if the remaining operator must cover both zones or if Mold/Bladder/Team Lead relief creates backlog in the helper's own work. Break coverage is therefore a time-phased capacity condition, not an informal support assumption.

Build a **Relief Capacity Reservation Matrix** for every planned break/lunch window and crew. Record: person on break; primary qualified relief; alternate relief; work transferred; expected relief duration; relief person's own due work during that window; actual break start/end; outside-support minutes; displaced helper work; and carryover after relief.

For each break window, recalculate the 30-minute capacity profile with the person on break removed and the relief person's own protected workload retained. A relief plan is not considered demonstrated merely because a qualified person exists. The system must show that coverage does not create hidden third-person dependency, missed protected work, persistent backlog, unsafe/quality-critical delay, or recurring overload elsewhere.

Do not invent an allowable utilization or missed-break threshold. Use plant-required break/safety/quality rules where they exist, then compare actual 3-op baseline and shadow-2-op relief performance under identical definitions. NIOSH guidance for extended shifts supports deliberately scheduling breaks and establishing duty coverage; Lean standardized work supports making manual work, walking and machine interaction explicit rather than hiding transferred work.

## Best current strategy
1. Map presses/travel and remove avoidable motion; compare candidate zone layouts on occupied work + peaks + travel.
2. Standardize protected routine work and signal-driven abnormal-response ownership.
3. Verify two-deep critical-task qualification across crews.
4. Build the Relief Capacity Reservation Matrix by crew and break window; retain the relief person's own workload in the calculation.
5. Prove time-phased capacity, including measured travel, abnormal demand, routine work and break windows.
6. Freeze measurement definitions, Leader Standard Work, SIC cadence and escalation authority.
7. Collect a context-characterized 3-op baseline using identical SIC, intervention, dependency, backlog, travel and relief measures.
8. Shadow 2-op and measure concurrent alarm demand, staffing-dependent support, displaced work, backlog aging, relief exceptions and route exceptions.
9. Pareto overload/interventions/backlog/relief failures; revise zones, standard work and support rules.
10. Run sustained A/B/C/D rotation; move to true 2-op only after representative conditions pass without hidden support, recurring negative capacity margin, protected-work failure, missed relief or persistent backlog.

## Pilot gates
- **Gate 0 — Data/design:** mapped layout, normalized alarm evidence, travel study and workload/travel-balanced candidate zones.
- **Gate 1 — Standard work/skills:** routine-work matrix, response matrix, verified critical-task coverage and future-state route.
- **Gate 2 — Relief/capacity:** completed Relief Capacity Reservation Matrix plus preliminary 30-minute capacity profile for normal and break windows.
- **Gate 3 — Management/measurement:** measurement dictionary, observer check, Leader Standard Work, visual controls, SIC ownership and intervention taxonomy.
- **Gate 4 — Baseline/context:** current 3-op state measured with identical definitions, including actual relief performance.
- **Gate 5 — Shadow 2-op:** capture busy/free state, response labor, interventions, relief exceptions, displaced work, recovery aging and route exceptions.
- **Gate 6 — Revise:** Pareto causes and revise the operating system.
- **Gate 7 — Sustained trial:** full crew rotation without hidden support, recurring overload, missed protected work, failed relief or persistent carryover.
- **Gate 8 — True 2-op/control:** demonstrated acceptance across representative conditions; controlled standard work, skills, relief, escalation, SIC and control plan.
