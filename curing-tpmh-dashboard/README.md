## Latest improvement — Multidimensional Pilot Evidence Matrix
**Do not allow TPMH alone to pass the 2-operator model.** Productivity can improve while work is delayed, outside labor is borrowed, response deteriorates, or backlog is handed to the next period. Thursday should therefore be judged across separate evidence dimensions, each tied to observed data and existing plant requirements.

### Evidence dimensions
1. **Safety / quality / authorization:** existing plant requirements satisfied; required containment, restart and two-person work covered by qualified people.
2. **Output / productivity:** cured tires, man-hours and TPMH, normalized for running press-hours, mix and downtime where possible.
3. **Work completion / service:** protected work completed within actual due requirements; Pending Work, oldest age, carryover and Recovery Debt visible.
4. **Abnormal response:** response milestones, simultaneous demand, qualification waits, saturation and recovery after surges.
5. **Labor independence:** outside intervention/support minutes and reason; distinguish normal frozen-model support from pilot-only rescue.
6. **Work-method stability:** PRIMARY/FLEX adherence, interruptions, route deviations, retrieval/backtracking and handoff failures.
7. **Relief sustainability:** breaks covered by qualified relief without simply displacing backlog or overloading a donor role.

### Interpretation rule
A strong TPMH result is **not sufficient evidence of 2-operator feasibility** if another required dimension fails. Conversely, one abnormal event does not automatically disprove feasibility: classify whether it reflects true capacity, qualification, dispatch, relief, motion/layout, model error, equipment condition or an existing plant-required containment response. Use actual plant limits; do not invent numerical acceptance thresholds.

### Pilot evidence states
For each dimension report **SUPPORTED / CONCERN / NOT TESTED / NOT VERIFIED**. Important demand states that do not occur Thursday remain NOT TESTED rather than being silently counted as a pass. This makes the pilot conclusion auditable and prevents a low-demand shift or borrowed labor from creating a false green result.
