## Latest improvement — Dual-Mode Pilot Observation
A single observer cannot continuously stopwatch both operators, abnormal events, relief, outside help and production context without creating missed events or observer interference. Thursday therefore uses two complementary observation modes.

### Mode A — continuous exception/event log
Continuously timestamp only meaningful events: abnormality, flex assist, third-person intervention, exposure-state change, break/relief handoff, delayed/protected work, rescue/containment, major downtime and recovery completion.

Record: `time | exposure state | Op1 activity | Op2 activity | event | owner | response start | flex? | extra helper? | support class | displaced work | recovery complete | note`.

### Mode B — fixed 15-minute structured observation each hour
At a preselected clock window each hour, observe both operators more closely for 15 minutes. Capture work category, walking/retrieval, waiting/monitoring, machine interaction, zone adherence, overlapping demand, relief state and any work carried forward. Do not move the window after seeing workload; a fixed window reduces cherry-picking.

At the end of each 15-minute window complete the five process-confirmation checks: YES / NO / NOT OBSERVABLE.

This produces representative repeated snapshots across the 12-hour shift while Mode A protects the high-value exception record. The 15-minute snapshots are diagnostic samples, not a claim of full-shift utilization unless a statistically defensible sampling design is later established.

## Pilot Process Confirmation Card
At each structured observation mark **YES / NO / NOT OBSERVABLE**:
1. Op1/Op2 follow frozen primary ownership unless a logged flex transfer is active.
2. Each abnormality has one clear primary owner.
3. Flex assist follows CALL → CHECK → TRANSFER → WORK → RETURN → RECOVER; displaced work remains visible.
4. Break/meal handoff occurs as designed without hidden uncovered work.
5. Any third-person production assistance is logged with reason, support class and people-minutes.

For every NO record `time | check | deviation | reason | consequence | containment | follow-up owner`. Later classify DESIGN GAP, TRAINING/CLARITY GAP, SPECIAL CAUSE, NON-ADHERENCE or INSUFFICIENT EVIDENCE. No invented conformance threshold.

## Controlled Flex-Assist Rule
Primary zones remain fixed. When uneven abnormal demand threatens due/protected work, use **CALL → CHECK → TRANSFER → WORK → RETURN → RECOVER**. The assisting operator must be qualified and must not abandon higher-priority/protected work. Record assist start/end, reason, displaced work and recovery. Repeated one-way borrowing is evidence to rebalance zones rather than normalize chronic flex.

## Support Neutrality Rule
For every non-Op1/Op2 intervention classify support as **BASELINE-NORMAL**, **INCREMENTAL-2OP**, **AMBIGUOUS**, or **CONTAINMENT/RESCUE** based on work/reason, not helper title. Incremental staffing-substitution people-minutes are charged to Effective Labor.

## Pilot Integrity Exposure States
- **INDEPENDENT 2-OP:** frozen method + normal baseline support only.
- **ASSISTED 2-OP:** incremental third-person staffing substitution occurs.
- **CONTAINED / NOT TESTABLE:** rescue/special cause means the frozen staffing concept is temporarily not being tested.

`Independent Exposure % = Independent 2-op minutes / observable pilot minutes × 100`
