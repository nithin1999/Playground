## Latest improvement — Demonstrated Skill-Readiness Gate
A binary qualification matrix can overstate usable coverage. Before a person is counted as independent Op1/Op2, break relief, or abnormal-response capacity, verify demonstrated task performance rather than relying only on a qualification label.

Use a four-state evidence ladder for each critical task/person pair: **Not trained → Trained/observed → Demonstrated with coaching → Demonstrated independently**. Plant authorization and safety/quality requirements always override this project classification. Only independently demonstrated capability should be counted as independent coverage in the pilot capacity model; coached performance remains useful training evidence but requires support and must not be counted as free capacity.

For high-consequence or abnormal work, use a short TWI-style Job Breakdown: important steps, key points, and reasons why. Have the candidate perform/teach back the task under representative conditions. Include abnormal-response and break-relief scenarios where practical. Record date, task, observer, evidence state, restrictions, and refresher/retest need.

This converts the Relief Coverage Feasibility Matrix from a static roster into an evidence-based **Skill × Coverage × Time** control. It also prevents a shadow pilot from appearing feasible because the third person is quietly coaching or rescuing nominally qualified operators.
