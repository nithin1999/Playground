Latest improvement — Break-Relief Handoff Standard

Break coverage is now treated as a planned role substitution, not informal help. The operator is released only after a qualified relief person accepts zone ownership and the current abnormal/recovery queue.

Handoff: zone/press ownership → active abnormalities → open queue → protected work due → known constraints → relief accepts → operator released.
Return: reverse the handoff; close or explicitly reassign anything still open.
Account: the relief person's home-role work remains demand. Measure displaced work/carryover and support people-minutes.
Validate: use the same handoff fields in the 3-op baseline and shadow 2-op so incremental relief burden is visible.

No break duration, delay limit or staffing threshold is invented; use plant requirements and measured evidence.
