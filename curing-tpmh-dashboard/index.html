Latest improvement — Qualification-Constrained Capacity

The Interval Load Index assumes operator-minutes are interchangeable. They are not if only one operator is qualified/authorized for work that becomes due, or if a task requires two qualified people.

For every task family mark Thursday coverage as BOTH / OP1 ONLY / OP2 ONLY / TWO-PERSON / NOT VERIFIED. For each 15-minute window, first calculate the aggregate Interval Load Index, then compare skill-restricted due work with the available minutes of operators actually qualified for that work.

If aggregate load is below 100% but skill-restricted work exceeds qualified capacity, classify the window QUALIFICATION-CONSTRAINED. Log waits caused solely by qualification separately. Leader/flex/rescue qualification stays outside normal two-operator capacity.

Why it matters

The model totals 736 min (12.27 labor-hours) versus 22 net two-operator hours, but 55.8% aggregate utilization does not prove that usable capacity exists for every required task. A skill bottleneck can overload one operator while nominal capacity remains on the other. This distinguishes a cross-training/authorization problem from a true third-operator requirement.
