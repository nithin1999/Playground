Latest improvement — Pilot Containment + Restart Logic

The first 2-operator exposure is now controlled with an explicit CONTAIN → STABILIZE → RECORD → RESTART loop. Green/Amber/Red escalation alone was not enough to distinguish temporary containment from a staffing-design weakness.

Contain: if an existing plant-required safety/quality/process limit is reached, or the authorized leader determines control is threatened, use the approved backup/escalation path immediately.
Stabilize: restore the approved operating condition before pursuing additional pilot learning.
Record: capture trigger, operator states, pending work, support people-minutes, recovery and preliminary cause class.
Restart: only under pre-approved authority after required containment/recovery. Repeated 2-op design causes become redesign items, not normalized pilot events.

No numeric stop/restart limit is invented here. Existing plant requirements govern safety/quality/process limits; baseline and pilot evidence govern staffing-design learning.
