Latest improvement — Abnormality Queue-Minutes Congestion Gate

Add a time-based congestion measure to the abnormal-response clock. A brief collision and a sustained backlog should not count the same.

QUEUE-MINUTES: sum each abnormality's waiting time before response starts; equivalently, area under the waiting queue-depth-versus-time curve.
SHAPE: also track peak waiting depth, oldest waiting age, minutes with queue > 0 and whether the queue fully clears.
SEPARATE: queue time is not hands-on labor; retain hands-on and recovery people-minutes separately.
STRATIFY: compare by zone, shift phase, break/non-break, production exposure and workload state.
DISPATCH: approved safety/quality criticality first; FIFO only within equivalent priority.
VERIFY: do not invent queue limits; derive acceptance from plant requirements and observed baseline/pilot evidence.

Best current strategy

  1. Map and reduce frequency-weighted route burden; verify motion savings.
  2. Demand-weight Op1/Op2 zones by remaining manual work + travel + abnormal exposure.
  3. Build individual capacity envelopes and collision reserve.
  4. Prove skill readiness and time-phased qualified relief.
  5. Freeze normal routes, protected work and workload states.
  6. Use signal → acknowledge → arrival → hands-on → containment → recovery timestamps.
  7. Use visible criticality/FIFO dispatch with named ownership and waiting age.
  8. Measure Queue-Minutes, peak waiting depth, oldest age and queue-clear recovery.
  9. Account for relief debt and home-role recovery labor.
  10. Collect context-characterized 3-op baseline and Exposure Signatures.
  11. Freeze GO / HOLD / STOP criteria and shadow rescue rules.
  12. Run shadow 2-op with rescue-only third operator; log every intervention.
  13. Compare exposure-matched windows using TPMH, Effective Labor, Support Burden, Adjusted TPMH, route burden and response/queue distributions.
  14. Pareto exceptions, redesign and repeat across representative A/B/C/D conditions before true 2-op.
