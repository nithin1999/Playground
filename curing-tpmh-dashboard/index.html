Latest improvement — Dual-Mode Observation

Protect Thursday from observer overload by separating continuous exception capture from structured sampling.

Mode A — Continuous: timestamp abnormalities, flex assists, third-person help, exposure-state changes, breaks/relief, delayed work, containment, major downtime and recovery.
Mode B — 15 min/hour: use a fixed preselected 15-minute window each hour to observe both operators closely: work category, walking/retrieval, waiting/monitoring, machine interaction, zone adherence, overlapping demand, relief state and carryover work.

Do not move a window because the shift looks busy or quiet. Complete the five process-confirmation checks at the end of each window. These snapshots are diagnostic; do not claim they represent full-shift utilization without an adequate sampling design.

Pilot Process Confirmation

During each fixed window mark YES / NO / NOT OBSERVABLE for: primary ownership, one owner per abnormality, flex discipline, break/relief handoff, and logging of third-person assistance.

Pilot integrity

INDEPENDENT 2-OP = frozen method + normal baseline support. ASSISTED 2-OP = incremental third-person staffing substitution. CONTAINED = rescue/special cause means the concept is temporarily not being tested.

Independent Exposure % = Independent 2-op minutes / observable pilot minutes × 100

Controlled Flex-Assist

Keep primary zones. Use CALL → CHECK → TRANSFER → WORK → RETURN → RECOVER when uneven demand requires internal assistance. Repeated one-way borrowing is evidence to rebalance zones.
