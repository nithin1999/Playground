Latest improvement — Shadow Rescue Intervention Protocol

A shadow pilot can look successful because a third person quietly supplies labor, decisions, reminders or coaching. Freeze the intervention rules before the first shadow window and make every intervention visible.

OBSERVE: shadow does not direct, remind, coach, fetch, perform production work or pre-position resources beyond the approved method.
CALL / RESPOND: Op1/Op2 signal abnormalities through the agreed escalation rule; record responder, arrival, reason and people-minutes.
RESCUE: intervene immediately when an existing safety/quality stop rule or predeclared rescue condition is reached. Record trigger, action, start/finish and displaced work.
RECOVER: track backlog, protected work, relief debt and return to normal ownership.
Evidence rule: rescued windows remain useful stress-test evidence but do not count as independent 2-op proof.
