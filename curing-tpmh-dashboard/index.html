Capacity Margin Profile

Margin = available operator minutes − occupied work minutes

  1. Build 30-minute buckets for Op 1 and Op 2 across the 12-hour shift.
  2. Occupied work = routine hands-on + alarm hands-on + necessary walking + relief/support obligations.
  3. Exclude unattended automatic press processing.
  4. Mark negative-margin intervals and every outside intervention.
  5. Pareto the causes after shadow testing.
  6. Do not invent a reserve threshold; establish it from baseline/shadow evidence and plant requirements.

Why this changes the design

Average ≠ peak capacity
~55% average utilization can coexist with short overload intervals.
Target observations
Use the profile to identify the exact time blocks/tasks where response-time or walking measurements are needed.
No hidden labor
Third-operator, Team Lead, Mold/Bladder or Gantry support minutes must appear in the same timeline.

Best current strategy

  1. Map press layout and make alarm source visible.
  2. Balance Op 1/Op 2 by occupied workload, peaks and travel.
  3. Create two-operator standardized work and task-qualified backup.
  4. Overlay 30-minute capacity margin with break-relief coverage.
  5. Create Pilot Acceptance Matrix + Leader Standard Work.
  6. Use point-of-use staging to reduce routine travel.
  7. Baseline → shadow 2-op → Pareto/revise → sustained rotation → true 2-op.
