Latest improvement: Abnormal-Work Dispatch / Ownership Standard

The pilot now needs an explicit rule for who responds to what when simultaneous demands appear. Undefined ownership can make two operators duplicate response, cross zones unnecessarily, or let older/protected work age. That is a coordination loss and must not automatically be interpreted as insufficient manpower.

Visual dispatch rule

  1. Existing safety, quality, equipment-protection and authorized escalation rules override productivity.
  2. If only one operator is qualified, that operator owns the event and the other protects base work.
  3. Otherwise use frozen PRIMARY ownership first.
  4. FLEX crosses zones only when PRIMARY is committed, unavailable/on break, or an existing reaction condition requires it.
  5. When eligible work competes, use existing due/response rules and oldest Pending Work rather than ad-hoc selection.
  6. Transfers are explicit: ACCEPTED → WORKING → CLEARED. External help remains charged to effective manning.
