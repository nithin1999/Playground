Latest improvement — Due-Time Recovery Queue / Work-at-Risk Control

A two-operator system can appear productive while required work accumulates behind abnormal responses. Queue age alone is not enough: the visual control must show which deferred item is closest to violating its applicable completion window.

Capture: task/press, owner, deferred time, required-by/completion window, remaining work if known, qualification, reason deferred and recovery owner.
Prioritize: plant safety/quality/process priority and time-to-breach over simple FIFO. Existing plant requirements always override queue order.
Visual states: RECOVERABLE / AT RISK / ESCALATE. Do not invent numeric limits where the plant has not defined a requirement; collect evidence first.
Interpretation: good TPMH is not sufficient if required work is merely deferred, rescued by hidden support, or carried beyond its required window.

Best current strategy

  1. Remove avoidable motion and point-of-use gaps.
  2. Demand-weight Op1/Op2 zones by work + travel + abnormal exposure.
  3. Build fixed-window Variability-Aware Reserve distributions.
  4. Test Cross-Zone Collision exposure/shared-resource conflicts.
  5. Apply Qualification Redundancy / Pair-Robustness Gate.
  6. Freeze NORMAL routes and single-owner ABNORMAL dispatch.
  7. Use Live Abnormality Ownership Board with explicit event states.
  8. Protect due work with a plant-approved Protected Work Matrix.
  9. Use Due-Time Recovery Queue with required-by/time-to-breach, qualification and recovery ownership.
  10. Close critical single-point skill gaps.
  11. Use formal break handoffs and retain relief home-role demand.
  12. Use Pilot Leader Standard Work without hidden third-operator labor.
  13. Sample Process Confirmation on critical standard-work behaviors.
  14. Run Pre-Pilot Scenario Challenge.
  15. Freeze measurement/escalation/containment definitions.
  16. Apply Pre-Exposure Readiness Gate and start a Change-Point Log.
  17. Collect matched, context-characterized 3-op baseline.
  18. Run controlled shadow 2-op with rescue-only third operator; log every intervention.
  19. Calculate scheduled TPMH, Effective Labor, Support Burden and Adjusted TPMH.
  20. Compare matched stable-condition segments for workload, collisions, response, time-to-breach/recovery, support, adherence and intervention evidence.
  21. Pareto exceptions and redesign.
  22. Repeat across demand, downtime, breaks, late-shift and A/B/C/D conditions before true 2-op.
