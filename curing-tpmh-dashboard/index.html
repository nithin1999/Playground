Latest improvement: add Short Interval Control (SIC) to the shadow and sustained pilots. End-of-shift TPMH is too late to reveal when overload, hidden support or backlog begins accumulating. Start with six 2-hour reviews per 12-hour shift unless YTMM already uses a stronger plant-standard cadence.

Short-interval pilot control

  1. Use the plant's existing interval production plan; do not invent a new target.
  2. At each review capture plan vs actual, press-hours/major downtime and safety/quality abnormalities.
  3. Flag Op 1/Op 2 negative capacity-margin intervals and outside-support/intervention minutes.
  4. Check Mold/Bladder carryover risk so labor is not merely displaced.
  5. Assign one recovery/countermeasure action and owner for the next interval when abnormal.
  6. Use the same SIC strip during the 3-op baseline and 2-op pilot for comparability.

Why this changes the design

Catch deterioration inside the shift
A shift can finish near target while containing temporary periods where two operators could not sustain the system.
Expose hidden labor
Outside-support minutes become visible at the interval where they were required instead of disappearing into shift totals.
Close the PDCA loop
Use the immediate past interval to choose the next recovery action rather than waiting for an end-of-shift review.

Best current strategy

  1. Map presses and balance zones by occupied workload, peaks and travel.
  2. Standardize predictable work; keep abnormalities signal-driven.
  3. Prove break relief and 30-minute capacity margin.
  4. Freeze measurement definitions, escalation authority and leader standard work.
  5. Collect context-characterized 3-op baseline with the same SIC strip.
  6. Shadow 2-op with short-interval control → intervention/interval-miss Pareto → revise.
  7. Sustained A/B/C/D rotation → true 2-op only after acceptance gates pass.
