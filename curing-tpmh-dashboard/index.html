Latest improvement — Predeclared Pilot Decision Gate

Freeze success/failure logic before shadow 2-op results are seen. Use existing plant requirements and defensible baseline evidence; do not invent thresholds to make the pilot pass.

GO: hard safety/quality requirements met; required work and relief controlled; no unresolved hidden-support dependency; capacity/recovery evidence acceptable under the observed Exposure Signature.
HOLD — REDESIGN: recurring saturation, coverage/skill gaps, relief debt, unrecovered protected work, dispatch ambiguity, or coaching/rescue dependency indicates the method is not yet self-sustaining.
STOP — CONTAIN: follow existing plant stop/containment rules for safety, quality, prohibited bypasses or other mandatory conditions. Productivity never overrides a hard gate.
Evidence rule: one good window is learning evidence, not permanent 2-op proof. Repeat representative exposure across crews and stress conditions.

Best current strategy

  1. Remove avoidable motion and point-of-use gaps.
  2. Demand-weight Op1/Op2 zones by work + travel + abnormal exposure.
  3. Build interval Operator-Minute Capacity Envelope and usable reserve.
  4. Test variability, cross-zone collisions and shared resources.
  5. Apply Demonstrated Skill-Readiness Gate and time-phased relief coverage.
  6. Freeze NORMAL routes, ABNORMAL dispatch and workload-state rules.
  7. Protect due work with Protected Work Matrix + Due-Time Recovery Queue.
  8. Use qualified break relief and account for relief debt/home-role recovery.
  9. Use leader standard work, process confirmation, scenario challenge and readiness gate.
  10. Collect context-characterized 3-op baseline with interval capacity ledger.
  11. Build an Exposure Signature for every baseline/shadow window.
  12. Freeze GO / HOLD-REDESIGN / STOP-CONTAIN decision criteria before shadow results.
  13. Run controlled shadow 2-op with rescue-only third operator; log coaching/rescue.
  14. Classify each window against the frozen decision gate.
  15. Compare exposure-matched/stratified windows and retain unmatched stress windows.
  16. Calculate TPMH, Effective Labor, Support Burden and Adjusted TPMH.
  17. Compare reserve, saturation, collisions, skill/coverage gaps, protected work, relief debt and recovery.
  18. Apply Time-of-Shift Robustness Gate across the 12-hour operating window.
  19. Pareto exceptions, redesign and repeat across representative A/B/C/D conditions before true 2-op.
