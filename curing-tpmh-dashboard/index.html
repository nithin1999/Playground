Latest improvement — Trigger-Based Abnormal Response Ladder

The pilot now separates unclear response rules from true manpower shortage. Use existing plant-authorized rules; do not invent time thresholds.

NORMAL ROUTE → ABNORMALITY VISIBLE/CALLED → PRIMARY OWNER → FLEX OWNER WHEN REQUIRED → FLOOR LEADER → CONTAINMENT/RESCUE → BACKLOG RECOVERY → NORMAL ROUTE

For each meaningful abnormality capture: visible/call time, owner/arrival, flex call/arrival, leader call/arrival, rescue/containment, competing work, backlog created and route-restored time.

Leader/flex help is not automatically a 2-op failure. Classify whether it is normal baseline support or incremental capacity required by the 2-op design, and retain people-minutes.

Hour-by-Hour Demand-to-Capacity Board

Capture plan/actual, running presses, abnormal events, Op1/Op2 direct work, walk/retrieval, queues, oldest backlog, relief/support, independent exposure and dominant cause. Use plant requirements—not invented limits—for GREEN/YELLOW/RED classification.

Exposure Coverage Matrix

Classify critical states OBSERVED-INDEPENDENT / OBSERVED-ASSISTED / CONTAINED / NOT-EXPOSED. NOT-EXPOSED remains a validation gap.
