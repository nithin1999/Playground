Latest improvement: freeze the Pilot Measurement Dictionary before baseline collection. The pilot cannot be trusted if different observers/crews classify alarm labor, walking, support, downtime or interventions differently.

Measurement-definition gate

  1. Use one primary activity code per occupied interval; secondary tags may describe contributing conditions.
  2. For abnormalities capture event start, notification, arrival, hands-on start/end and equipment clear where available.
  3. Never substitute machine alarm duration for operator hands-on labor.
  4. Record provider/role and minutes for every outside-support intervention.
  5. Freeze definitions for walking, relief, GIP, checks, manual handling, support, backlog, press-hours and staffing-attributable downtime.
  6. Have two observers independently code the same short representative window; reconcile differences before formal baseline.

Why this changes the design

Comparable evidence
Baseline and pilot must use the same operational definitions and instruments.
No double counting
Mutually exclusive primary codes keep intervention and capacity-minute totals auditable.
No invented threshold
Do not impose an observer-agreement cutoff unless YTMM has one; reconcile and repeat until the coding is operationally consistent.

Best current strategy

  1. Map presses and make alarm source visible.
  2. Balance Op 1/Op 2 by occupied workload, peaks and travel.
  3. Create standardized predictable work; keep abnormalities signal-driven.
  4. Prove break relief and 30-minute capacity margin.
  5. Freeze measurement definitions and escalation/leader standard work.
  6. Collect context-characterized 3-op baseline.
  7. Shadow 2-op → intervention Pareto → revise → sustained A/B/C/D rotation → true 2-op.
