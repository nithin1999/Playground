Latest strategy improvement: add a time-phased demand-state gate. Aggregate utilization is no longer sufficient by itself to approve the two-operator pilot.

Why this changed

The current aggregate workload result suggests substantial two-person capacity, but a 12-hour average can conceal short periods where alarms, GIP, checks, breaks or manual work overlap. The design must prove that two operators can cover the work through the shift, not only on average.

Build a 30-minute demand profile
Use 60-minute buckets only if observations are too sparse. Stack occupied labor by Operator 1 and Operator 2 in each bucket.
Separate machine time from people time
Count hands-on work, necessary walking and coverage; do not count unattended automatic processing as occupied labor.

Demand-state classification

Green
Both operators perform assigned work and maintain required press coverage.
Yellow
Temporary cross-support is needed but the two-person system can recover without outside help.
Red
Two operators cannot maintain required coverage/work; qualified backup is required.

No invented numerical thresholds. Calibrate the states from shadow-pilot interventions and measured response labor.

Current best strategy

  1. Make alarm source visible and map every press.
  2. Balance Op 1 / Op 2 by occupied workload, not press count.
  3. Build the time-phased Green/Yellow/Red demand profile.
  4. Compare upper/lower vs left/right ownership using workload, peaks and travel.
  5. Use point-of-use staging to remove routine material walking.
  6. Define qualified backup and integrated break relief.
  7. Protect Mold/Bladder due work; extended abnormalities escalate.
  8. Baseline → shadow 2-op → sustained rotation → true 2-op.

Next action

Create the 12-hour demand-state chart
For each time bucket: alarm hands-on work + GIP/material + checks + manual work + necessary walking + break coverage.
Instrument the shadow pilot
Log every third-operator intervention: timestamp, reason, press, duration, who was occupied and whether future qualified backup could cover it.
