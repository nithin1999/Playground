Pre-Pilot Readiness Gate

Use GO / GO-WITH-CONTAINMENT / NOT-READY before exposure. Freeze standard work, qualified capacity, abnormal response, relief and measurement. Existing plant safety, quality and process requirements remain authoritative.

Pilot integrity

Observer records without coaching; floor leader retains normal plant authority; rescue/shadow intervenes through existing rules or the agreed containment boundary. Classify support as BASELINE-NORMAL / INCREMENTAL-2OP / OBSERVER-INFLUENCED / CONTAINMENT-RESCUE / AMBIGUOUS.
