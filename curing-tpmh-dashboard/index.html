Decision logic

If observed Thursday category minutes materially disagree with the model, fix the workload model before making a staffing conclusion. If the model reconciles but both operators saturate during clustered surge demand, treat that as a surge/capacity design problem. If one operator overloads while the other retains capacity, rebalance routes/ownership. Borrowed labor remains explicit.
