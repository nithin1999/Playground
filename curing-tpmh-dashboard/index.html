Latest improvement — Interval Capacity Stress Test

The 55.8% shift-average utilization and 9.73 nominal reserve hours can hide local overload. Use the existing 15-minute windows to test whether capacity exists when demand actually occurs.

Interval Load Index = Due/Committed Work Minutes ÷ Available 2-Operator Minutes. Two fully available operators provide 30 operator-minutes in a 15-minute window. Adjust for actual break/unavailability. Keep leader/flex/outside-support minutes separate so borrowed labor cannot silently validate the two-operator model.

Pair the index with queue growth, oldest waiting work, Recovery Debt, response latency and support minutes. A window above 100% means due/committed labor exceeded available two-operator capacity for that interval; do not invent a lower acceptance threshold. Analyze NORMAL, BREAK-RELIEF and SURGE/SATURATION separately.
