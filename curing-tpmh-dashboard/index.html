Latest improvement - Interruption-Recovery Standard

Thursday must test whether normal periodic and protected work recovers after event-driven interruptions, not merely whether alarms are answered.

Sequence: INTERRUPT - RESPOND - CHECK DUE WORK - RESUME HIGHEST-PRIORITY DUE WORK - CLEAR BACKLOG - RETURN TO NORMAL ROUTE.

CapturePurpose
Route or task interruptedIdentify displaced normal work
Response completeSeparate response from recovery
Next protected task dueExpose timing conflict
Route resumedMeasure interruption recovery
Overdue work and helperExpose hidden backlog or extra support
Backlog-clear timeMeasure return to stable condition

Use existing plant requirements where available. No arbitrary recovery threshold is assumed.

Best current strategy

  1. Freeze people, zones, normal routes, qualifications, relief and reaction rules.
  2. List periodic and protected tasks with actual due-time requirements.
  3. Scenario-walk simultaneous demand, break abnormality, flex assist and two-person tasks.
  4. Rehearse interruption, response and route recovery.
  5. Run Thursday with exception logging, fixed observation windows and hourly production control.
  6. Reconstruct occupancy, queues, interruptions, backlog recovery and support.
  7. Normalize against running presses, events, mix and downtime.
  8. Compare early, middle and late shift robustness.
  9. Review TPMH, Effective Labor, Independent Exposure, support, relief debt and queue recovery.
  10. Pareto observed causes and repeat representative conditions before permanent staffing change.

Immediate next action

Draw the Op1 and Op2 normal routes and mark every periodic or protected task with its real due-time or frequency. Rehearse one alarm interruption for each operator and verify where the route resumes and how backlog is cleared. Add interruption, resume and backlog-clear timestamps to Thursday's observer sheet.
