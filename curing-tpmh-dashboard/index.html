Latest improvement: Observer / Leader Intervention Protocol

Freeze observer behavior before the trial so pilot-only help is not mistaken for two-operator capacity.

  • Observer: records only; no prompting, fetching, covering or pre-emptive problem solving.
  • Authorized support: normal-model work; record source, reason, task and duration.
  • Containment response: intervene whenever existing plant rules require it and record the trigger and duration.

Track Intervention Minutes, Intervention Count, Source Role and Reason. If observers repeatedly coach PRIMARY/FLEX, routes or Pending Work, the operating model is not yet self-executing.
