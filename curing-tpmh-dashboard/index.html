2-Operator Layout — Current Design Direction

Primary concept
Operator 1 covers the upper lane; Operator 2 covers the lower lane. Both use the center crossover for support where practical.
Routine movement
Standardize inspection, GIP, documentation and 2S routes. Do not force a fixed alarm route.
Alarm response
Assigned operator responds directly; second operator assists only when alarms overlap or abnormal work exceeds one operator.
Validation still needed
Compare top/bottom ownership against left/right geographic ownership using press-level workload and travel distance.
