Latest improvement — Exposure-Matched Pilot Comparison Gate

Do not attribute a shift-to-shift TPMH difference to staffing when the operating opportunity changed. Characterize every 3-op baseline and shadow 2-op window with an Exposure Signature.

Exposure Signature: running press-hours/cycles • planned/actual production opportunity • product/mix • major press/gantry downtime • abnormal-event and observed hands-on demand • break/relief exposure • staffing/qualification state • material special conditions.
Comparison rule: compare reasonably matched windows or stratify by the nuisance factor. Do not pool unlike conditions into one staffing average.
Stress evidence: never discard difficult 2-op windows merely because no clean 3-op match exists. Retain them separately as robustness evidence.
No premature equivalence: a small number of matched windows cannot prove permanent 2-op capability.

Best current strategy

  1. Remove avoidable motion and point-of-use gaps.
  2. Demand-weight Op1/Op2 zones by work + travel + abnormal exposure.
  3. Build interval Operator-Minute Capacity Envelope and usable reserve.
  4. Test variability, cross-zone collisions and shared resources.
  5. Apply Demonstrated Skill-Readiness Gate and time-phased relief coverage.
  6. Freeze NORMAL routes, ABNORMAL dispatch and workload-state rules.
  7. Protect due work with Protected Work Matrix + Due-Time Recovery Queue.
  8. Use qualified break relief and account for relief debt/home-role recovery.
  9. Use leader standard work, process confirmation, scenario challenge and readiness gate.
  10. Collect context-characterized 3-op baseline with interval capacity ledger.
  11. Build an Exposure Signature for every baseline/shadow window.
  12. Run controlled shadow 2-op with rescue-only third operator; log coaching/rescue.
  13. Compare exposure-matched/stratified windows and retain unmatched stress windows.
  14. Calculate TPMH, Effective Labor, Support Burden and Adjusted TPMH.
  15. Compare reserve, saturation, collisions, skill/coverage gaps, protected work, relief debt and recovery.
  16. Apply Time-of-Shift Robustness Gate across the 12-hour operating window.
  17. Pareto exceptions, redesign and repeat across representative A/B/C/D conditions before true 2-op.
