Latest improvement — time-of-shift robustness

Do not accept the 2-operator model only from shift-average TPMH/utilization. Because the work uses 12-hour shifts, use the existing six 2-hour SIC blocks to test whether overload, outside support, missed relief, backlog or abnormal-response performance systematically worsens later in the shift. This is a validation check—not a claim that fatigue is currently causing a problem.

Rule: A good shift-end result is not robust if it repeatedly depends on late-shift overload, delayed/missed relief, hidden support or backlog recovery.
Analysis: Compare plan attainment, intervention/support minutes, negative capacity-margin intervals, relief exceptions, alarm-response measures when available, and safety/quality abnormalities by SIC block and day/night context.
Do not invent a threshold: first look for repeatable patterns; if one appears, Pareto the mechanism before attributing it to fatigue.

Best current strategy

  1. Map presses; balance zones by occupied workload, peaks and travel.
  2. Standardize predictable work; keep alarm response signal-driven.
  3. Prove break relief and 30-minute capacity margin.
  4. Freeze measurement definitions, escalation authority and leader standard work.
  5. Collect context-characterized 3-op baseline using the same SIC/time-of-shift fields.
  6. Shadow 2-op → intervention/overload/time-block Pareto → revise standard.
  7. Sustained A/B/C/D rotation → true 2-op only after all acceptance gates pass.
