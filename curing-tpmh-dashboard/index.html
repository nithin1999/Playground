Latest improvement — Qualification Redundancy / Pair-Robustness Gate

A 2-op layout can be balanced in minutes and still fail if only one person can perform a protected or abnormal task. Available minutes count as usable capacity only when the available person is qualified for the waiting work.

Task × Person matrix: classify every protected/abnormal task for Op1, Op2 and relief using verified plant-approved capability.
Coverage classes: dual-covered, single-covered, relief-dependent, or uncovered. Keep two-person/scarce-support tasks separate.
Stress the pair: test each task with Op1 unavailable/busy, Op2 unavailable/busy, and during each break state.
Training priority: close critical single-point gaps first using standardized task breakdowns and demonstrated qualification; do not treat attendance or familiarity as qualification.

Best current strategy

  1. Remove avoidable motion and point-of-use gaps.
  2. Build Demand-Weighted Operator Balance; define provisional zones by work content + travel + abnormal exposure.
  3. Build fixed-window Variability-Aware Reserve distributions for Op1, Op2 and the pair.
  4. Build Cross-Zone Collision Matrix and test alternate zone boundaries.
  5. Apply Qualification Redundancy / Pair-Robustness Gate so reserve is qualification-constrained.
  6. Freeze NORMAL routes and ABNORMAL single-owner dispatch.
  7. Protect due work with the Protected Work Matrix and visible recovery queue.
  8. Close critical single-point skill gaps with standardized training and demonstrated qualification.
  9. Use formal break handoffs and retain relief person's home-role demand.
  10. Freeze measurement, escalation and containment/restart rules.
  11. Collect context-characterized 3-op baseline with reserve + collision + skill-constraint evidence.
  12. Shadow 2-op; measure queue aging, support labor, breaks, containment and collision handling.
  13. Calculate scheduled TPMH, Effective Labor and Adjusted TPMH.
  14. Pareto exceptions; rebalance work/zone boundaries and training priorities.
  15. Expand across demand, downtime, late-shift and A/B/C/D conditions before true 2-op.
