Latest improvement — Abnormal-Response Clock

Alarm duration is not operator workload. Every abnormality should be decomposed into a visible response timeline so the pilot can distinguish signaling, queue/travel, hands-on labor, containment and recovery.

DETECT: machine/HMI/andon exposes the abnormality; reduce routine patrol where real-time signaling can direct attention.
ACKNOWLEDGE / OWN: one named operator accepts ownership; the other follows the defined normal route unless two-person response is required.
RESPOND: record queue and travel separately from hands-on work.
CONTAIN / ESCALATE: use existing plant safety, quality and response rules; do not invent time thresholds.
RECOVER: close the operating event only when displaced protected work, relief debt and recovery queue are controlled.

Best current strategy

  1. Remove avoidable motion and point-of-use gaps.
  2. Demand-weight Op1/Op2 zones by work + travel + abnormal exposure.
  3. Build individual capacity envelopes and collision reserve.
  4. Prove skill readiness and time-phased qualified relief.
  5. Freeze normal routes, abnormal ownership, protected-work priorities and workload states.
  6. Use signal → acknowledge → arrival → hands-on → containment → recovery timestamps for abnormalities.
  7. Account for relief debt and home-role recovery labor.
  8. Collect context-characterized 3-op baseline and Exposure Signatures.
  9. Freeze GO / HOLD / STOP criteria and shadow rescue rules.
  10. Run shadow 2-op with rescue-only third operator; log every intervention.
  11. Compare exposure-matched windows using TPMH, Effective Labor, Support Burden, Adjusted TPMH and response-clock distributions.
  12. Pareto exceptions, redesign and repeat across representative A/B/C/D conditions before true 2-op.
