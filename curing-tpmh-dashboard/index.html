Latest improvement — Base Load vs Surge Load

Do not size this machine-intensive system from one average utilization number. Build an observed work-combination view for each operator and separate repeatable base work from stochastic abnormal demand.

Work categoryUse
Manual workBase operator load
Walk / retrievalBase load + motion-reduction opportunity
Machine automatic timeKeep visible; do not count as operator labor
Protected / periodic workTime-normalize into base load; verify due-time compliance
Alarm / abnormal / recoverySurge load and reserve-capacity demand

Decision principle: low average utilization alone does not prove removable labor. The two-operator design needs normal work to fit with observable reserve, then must absorb/recover measured surge demand without recurring staffing substitution or overdue protected work.

Protected-Work Due-Time Control

Use real plant due times only: task | owner | due/interval | NEXT/DUE/OVERDUE | completed | displaced by | recovered.

Recovery Debt / Backlog Area

Record queue start, peak pending, oldest age, queue clear and route-restored time. Post-pilot calculate pending-work × minutes. High peak with fast recovery differs from modest backlog that persists.

Pilot HOLD / Containment

Plant Safety, Quality and equipment-protection requirements override the experiment. If independent 2-op exposure is lost: HOLD → contain/escalate → timestamp → preserve evidence → classify → authorized restart.

Leader Reserve + Support Displacement

Log every leader/flex/support assist with reason, people-minutes, backlog effect, donor-role displacement and restoration. Distinguish planned support, surge capacity, staffing substitution and containment.
