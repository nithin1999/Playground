Latest improvement — Shadow-Operator Rescue Protocol

The first reduced-manning exposure should be a controlled shadow 2-op experiment, not an informal three-person shift. Op1 and Op2 execute the proposed standard while a qualified third operator remains available as rescue capacity but performs no routine Op1/Op2 work.

Intervene only under existing plant authority: safety, quality, process, escalation, or authorized-leader condition. Do not invent a new numeric stop threshold.
Count every rescue: timestamp, trigger, Op1/Op2 state, queue/protected-work state, shadow action, hands-on + travel minutes, task/press, reason and recovery time.
Classify: special cause/plant-required; 2-op capacity/collision; qualification gap; break-relief gap; standard/adherence gap; or not yet classifiable.
Interpret correctly: repeated third-person production assistance is evidence against the current design, even if production recovers and TPMH looks good.

Best current strategy

  1. Remove avoidable motion and point-of-use gaps.
  2. Demand-weight Op1/Op2 zones by work + travel + abnormal exposure.
  3. Build fixed-window Variability-Aware Reserve distributions.
  4. Test Cross-Zone Collision exposure and shared-resource conflicts.
  5. Apply Qualification Redundancy / Pair-Robustness Gate.
  6. Freeze NORMAL routes and ABNORMAL single-owner dispatch.
  7. Protect due work with Protected Work Matrix + recovery queue.
  8. Close critical single-point skill gaps.
  9. Use formal break handoffs and retain relief home-role demand.
  10. Use Pilot Leader Standard Work without hidden third-operator labor.
  11. Run Pre-Pilot Scenario Challenge and close design ambiguities.
  12. Freeze measurement, escalation and containment/restart rules.
  13. Collect matched 3-op baseline.
  14. Run controlled shadow 2-op with third operator as rescue only; log every intervention.
  15. Calculate scheduled TPMH, Effective Labor and Adjusted TPMH including rescue/support labor.
  16. Pareto interventions, overload, collisions, due-time misses, skill/relief/adherence and redesign.
  17. Repeat shadow exposures across demand, downtime, breaks, late-shift and A/B/C/D conditions before true 2-op.

Next action

Prepare the first shadow exposure with an explicit rescue protocol. Designate the qualified third operator, brief that routine Op1/Op2 work is off-limits, preserve existing plant escalation authority, and add the intervention log to the observer sheet. Any production assistance by the shadow operator must be counted in Effective Labor/Support Burden.
