Latest improvement — Due-Time Protected-Work Control

The recovery queue now protects when work must be completed, not merely whether it eventually gets completed. A 2-op exposure can look successful while mandatory routine work silently ages during abnormalities.

Before pilot: build a plant-approved Protected Work Matrix: task → significance → required timing/frequency → permitted deferral if already defined → primary → qualified alternate → escalation → completion evidence.
During exposure: every displaced task gets Due Time, Queue Entry, Owner, Age and Recovery Time.
Dispatch: zone owner responds to abnormality; second operator protects highest-priority due work; deferrable work enters the visible recovery queue.
Judge: a cleared queue does not erase a due-time miss. Record and Pareto misses separately.

No due-time limit is invented; use existing plant work standards, safety/quality requirements and process-owner decisions.

Best current strategy

  1. Remove avoidable motion and balance zones on workload + peaks + travel.
  2. Freeze NORMAL routes and ABNORMAL dispatch with one owner per event.
  3. Define the Protected Work Matrix and task timing/ownership.
  4. Run a visible due-time recovery queue; displaced work remains demand until recovered.
  5. Verify actual Op1/Op2/relief skill coverage.
  6. Use qualified break-relief handoffs and retain relief-home-work demand.
  7. Build qualification- and due-time-constrained 30-minute Capacity Reserve + Recovery Profiles.
  8. Freeze measurement, escalation, SIC and containment/restart rules.
  9. Collect context-characterized 3-op baseline with identical due-time/relief/support definitions.
  10. Shadow 2-op and capture exceptions, queue aging, due-time misses, support labor, breaks and containment.
  11. Calculate scheduled TPMH, Effective Labor and Adjusted TPMH.
  12. Compare matched 3-op/2-op periods; Pareto overload/support/due-time/backlog/relief causes.
  13. Redesign and expand across late-shift, break, demand, downtime and A/B/C/D conditions before true 2-op.

Next action

Build the Protected Work Matrix before the first pilot. Pull timing/frequency from existing work instructions and quality/safety requirements. Add Due Time, Queue Entry, Owner, Age and Recovery Time to the observation sheet, then use the same fields during a representative 3-op baseline.
