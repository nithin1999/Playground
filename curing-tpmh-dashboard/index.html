Latest improvement — Abnormal-Work Dispatch + Visible Queue

The 2-operator design now requires explicit ownership of abnormal work so both operators do not duplicate response while routine work becomes orphaned.

Visual states: NEW → OWNED → WAITING/ESCALATED → RECOVERED.
Dispatch: zone owner is default first responder; Op2 continues protected due work unless a predefined cross-support trigger is met.
Recovery: displaced routine work stays visible with an owner and due requirement and remains in workload/capacity demand until recovered.

If neither qualified operator can absorb the event within plant requirements, use the Green/Amber/Red escalation path and log outside-support people-minutes. No arbitrary WIP, backlog or response thresholds are invented; use plant requirements and baseline evidence.

Best current strategy

  1. Map travel; remove avoidable motion; balance zones on workload + peaks + travel.
  2. Freeze NORMAL routes.
  3. Freeze ABNORMAL dispatch: zone owner first, cross-support trigger, one owner per event, escalation and return-to-standard.
  4. Use the visible recovery queue so interrupted work cannot disappear.
  5. Build demonstrated skill coverage for the actual Op1/Op2/relief pairing; close gaps with TWI/plant-approved training.
  6. Reserve real break-relief capacity.
  7. Build 30-minute Capacity Reserve + Recovery Profiles including qualification and unrecovered queue demand.
  8. Freeze measurement, Leader Standard Work, SIC and escalation authority.
  9. Freeze Context Card + Decision Scorecard + Exception Observation + support taxonomy.
  10. Collect context-characterized 3-op baseline including normal support and abnormal-work ownership.
  11. Shadow 2-op; capture exceptions, queue/recovery and support people-minutes; compare context-matched 3-op periods.
  12. Calculate scheduled TPMH, Effective Labor Hours, Support Burden and Adjusted TPMH; Pareto incremental support, duplicate response and structural overload.
  13. Revise and expand across underrepresented contexts and A/B/C/D crews; true 2-op only after representative gates pass without hidden labor transfer.
