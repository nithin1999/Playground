Current best strategy

  1. Keep two qualified people available at the presses.
  2. Map every press ID to its exact floor position.
  3. Build Operator 1 / Operator 2 Yamazumi using alarm response + GIP/material + checks + manual work + routine walking.
  4. Compare upper/lower vs left/right geographic ownership.
  5. Standardize predictable routes; keep alarm response direct and signal-driven.
  6. Use point-of-use supplies and material staging to reduce walking.
  7. Protect Mold/Bladder due work; extended abnormalities escalate.
  8. Baseline → shadow 2-op → sustained full-rotation trial → true 2-op.

Pilot gates

Gate 0 — Design readiness
Comparable/normalized alarm data, mapped press layout, balanced zone loads, relief schedule and backup qualifications.
Gate 1 — Baseline
Production, backlog, walking, alarms, breaks and support.
Gate 2 — Shadow 2-op
Third operator intervenes only when future-state rules cannot cope.
Gate 3 — Sustained trial
Full rotation; monitor Mold/Bladder backlog, production, response and support burden.
Gate 4 — True 2-op
Safety, coverage, production, workload and backlog stable.
