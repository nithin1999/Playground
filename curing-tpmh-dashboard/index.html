Latest improvement — 15-Minute Workload Saturation Test

Shift TPMH and hourly averages can hide short overloads. Thursday will add 15-minute windows to determine whether queues/backlog form when actual operator demand temporarily approaches available qualified capacity.

Capture: Op1/Op2 occupied minutes · walking/retrieval · abnormal-response work · protected work · break/relief state · queue/backlog start/peak/end · incremental support people-minutes · running presses · abnormal events · production context.
