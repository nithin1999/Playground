Latest improvement — protect routine work during abnormalities

The 2-operator test must measure not only whether alarms are answered, but what planned work gets displaced while operators answer them. Production can remain on plan while GIP/scan, checks, documentation, replenishment, manual work or relief is deferred, recovered later, or silently transferred to another role.

Normal: execute the defined routine sequence in balanced zones.
Abnormal: zone owner responds; qualified cross-support/escalation follows the response matrix.
Make displacement visible: mark interrupted/skipped routine work when the abnormality occurs.
Recover: return to standard and record who recovered the task and when.
Capacity exception: if protected work cannot be recovered without hidden support, missed relief, safety/quality exposure or carryover, treat it as a staffing-system exception even if output is on plan.

No arbitrary delay limits are assigned. Use existing plant requirements where available and baseline/shadow evidence otherwise.

Best current strategy

  1. Map presses; balance zones by occupied workload, peaks and travel.
  2. Define routine work sequence and Routine Work Protection Matrix.
  3. Keep abnormalities signal-driven with explicit ownership/cross-support/escalation.
  4. Verify two-deep critical-task coverage across crews and relief windows.
  5. Prove break relief and 30-minute capacity margin.
  6. Freeze measurement definitions, escalation authority and leader standard work.
  7. Collect context-characterized 3-op baseline with SIC and routine-work completion.
  8. Shadow 2-op: measure concurrent demand, all interventions and displaced/recovered work.
  9. Pareto overload + displaced work → revise → sustained A/B/C/D rotation → true 2-op only after gates pass.

Next action

Build the Routine Work Protection Matrix. Start with GIP/scan, checks/documentation, material replenishment, planned manual load/unload, scheduled monitoring and relief. Record normal owner, timing/trigger, plant-required priority/deadline if one exists, deferrability, recovery owner and actual completion/carryover. Add displaced task/minutes/recovery fields to the pilot intervention log.
