Latest improvement — Interruption / Restart-Loss Test

The 736-minute model can miss labor created when required work is started, interrupted by a higher-priority demand, and then requires return travel, re-orientation, rechecks or repeated work before completion.

Use the existing timestamp log and flag interrupted work. Capture original task, interruption, cause, operator, return, restart/re-orientation or repeated-work minutes, and completion.

Interruption Tax = restart/re-orientation + repeated-work minutes caused by interruptions. Also count fragmented tasks. Keep required safety/quality rechecks explicit; do not label them waste.

Why it matters

55.8% shift-average utilization may still overstate usable reserve if abnormal calls repeatedly fragment protected or periodic work. High interruption tax with low aggregate interval load points to dispatch, route, ownership or relief design before concluding that raw manpower is insufficient. Do not add a generic restart allowance until the pilot measures it.

Workload-model validation

Maintenance Support contributes 336 min (45.7%); Alarm Response + Maintenance Support + Bladder Support + Changeover Support total 548 min (74.5%). Validate Maintenance Support first and check whether existing task times already contain interruption/restart effects to avoid double counting.

Best current strategy

  1. Freeze roles, routes, verified qualifications, relief and reaction rules.
  2. Freeze/confidence-tag the 736-min model; validate Maintenance Support first.
  3. Map skill-restricted and two-person work.
  4. Assign PRIMARY/FLEX ownership, handoff and dispatch priority.
  5. Scenario-walk breaks, simultaneous abnormalities, skill-restricted overlaps and an interrupted protected task.
  6. Run Thursday with timestamped work, response milestones, 15-minute windows, queues, saturation, qualification waits, support and interruption flags.
  7. Reconcile actual category minutes/events to the workload model.
  8. Calculate Interval Load Index, qualification feasibility, fragmented-task count and Interruption Tax.
  9. Build NORMAL / BREAK-RELIEF / SURGE-SATURATION balance and response-time views.
  10. Reconstruct Recovery Debt, break debt, qualification waits, hidden support and route restoration.
  11. Normalize for press-hours, events, mix and downtime; compare matched shifts.
  12. Correct the demonstrated constraint—capacity, qualification, fragmentation, balance, motion, relief or model error—and repeat representative exposure before permanent change.

Immediate next action

Add one interruption flag to the existing pilot log. Scenario-walk a protected/periodic task interrupted by a higher-priority abnormal call and verify unfinished-work visibility, ownership, return and restart/recheck behavior.
