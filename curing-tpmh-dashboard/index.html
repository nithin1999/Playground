Safety decision: Tricycle rejected; ride-on mobility remains outside the future-state design.
Latest improvement — introduce a quantitative workload-balance gate. Do not approve the two-operator zone layout merely because total Curing utilization is low. Build each operator's load from observed work elements and require the two zone loads to be close enough that neither operator becomes the practical bottleneck. Use an Operator Balance Chart/Yamazumi to stack alarm-response labor, GIP/material work, inspections/checks, documentation, manual handling and routine walking by operator. Also track the longest/95th-percentile response burden separately because averages can hide event-driven overload.

Current best strategy

  1. Keep two qualified people available at the presses.
  2. Verify exact alarm source is visible before true 2-op.
  3. Measure work elements by press/zone and create an Operator Balance Chart for Op 1 vs Op 2.
  4. Compare upper/lower ownership with left/right geographic ownership using workload plus travel.
  5. Standardize predictable material/check routes; alarm response remains signal-driven.
  6. Reduce material travel with point-of-use staging and fixed replenishment routes rather than operator ride-on transport.
  7. Protect Mold/Bladder due work and escalate extended abnormalities.
  8. Baseline → shadow 2-op → sustained full-rotation trial → true 2-op.

Next action

Create the 2-operator Yamazumi
For each press/zone: alarms × hands-on response time + GIP/material + inspection/check + documentation + manual work + routine walking. Stack by proposed operator.
Provisional design criterion
Target the two operator loads within roughly 10% of each other during design. Treat this as an engineering screen, not a proven plant standard; final acceptance comes from the shadow/sustained pilot.
Stress test
In addition to mean labor, evaluate overlapping alarms and high-demand periods so a balanced average does not conceal short-duration overload.

Risks / gaps

  • No press-level workload dataset yet, so the upper/lower layout is still a hypothesis.
  • Alarm visibility effectiveness is not yet verified.
  • Mold/Bladder carryover and time-phased due work remain unproven.
  • Backup qualification and Team Lead real availability remain unverified.
  • Gantry manual-support burden still needs observed people × minutes.

Pilot gates

Gate 3 — Sustained trial
Consecutive shifts/full rotation; monitor backlog, production, response and support burden.
Gate 4 — True 2-op
Safety, coverage, production, workload and backlog stable.
