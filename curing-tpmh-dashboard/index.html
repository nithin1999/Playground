Safety decision: Tricycle rejected. Ride-on mobility is removed from the future-state design.
Latest evidence-based improvement: Make alarm visibility/andon effectiveness a pilot prerequisite, not a later enhancement. In machine-intensive processes, Lean guidance prioritizes directing operators to the machine that actually needs attention instead of relying on patrol/random walking. Therefore the motion study should separate signal-driven response travel from routine patrol/material travel. The latter is the main target for route and point-of-use kaizen.

Latest Strategy

  1. Keep two qualified people available at the presses at all times.
  2. Confirm operators can identify which press needs attention before traveling; close alarm-visibility gaps before true 2-op.
  3. Balance Operator 1 and Operator 2 by workload and response distance, not press count.
  4. Standardize predictable inspection/material routes; keep alarm response direct and event-driven.
  5. Reduce routine motion with point-of-use supplies, staging and Safety-approved handling methods.
  6. Protect Mold/Bladder due work; short backup is bounded and extended abnormalities escalate.
  7. Baseline → shadow 2-op → sustained full-rotation trial → true 2-op only after gates pass.

Pilot Gates

Gate 0 — Design readiness
Alarm source is visible, zones are workload-balanced, backup qualifications are defined, and relief schedule is feasible.
Gate 1 — Baseline
Collect current production, backlog, walking, alarms, breaks and support data.
Gate 2 — Shadow 2-op
Third operator observes and intervenes only when future-state rules cannot cope.
Gate 3 — Sustained trial
Run consecutive shifts/full crew rotation; monitor backlog, production, response and support burden.
Gate 4 — True 2-op
Proceed only when safety, coverage, production, workload and backlog remain stable.
