Latest improvement — Time-of-Shift Robustness Gate

A 12-hour staffing design should not be accepted from whole-shift averages alone. Test whether the method remains controlled through break/meal windows and the later portion of the shift.

BLOCK: use fixed clock blocks consistently across baseline and pilot; do not select favorable windows after results are known.
EXPOSURE: retain running presses, mix, downtime and abnormal demand inside each block.
STABILITY: compare Queue-Minutes/waiting, hands-on + recovery labor, route burden, protected work, relief debt, outside support and production by block.
INTERPRET: worsening late-shift behavior triggers investigation; it is not proof of fatigue by itself.
RELIEF: a method that works by delaying/skipping breaks or accumulating relief debt is not independent 2-op proof.
VERIFY: do not invent deterioration limits; use plant requirements and observed baseline/pilot distributions.

Best current strategy

  1. Map and reduce frequency-weighted route burden; verify motion savings.
  2. Demand-weight Op1/Op2 zones by remaining manual work + travel + abnormal exposure.
  3. Build individual capacity envelopes and collision reserve.
  4. Prove skill readiness and time-phased qualified relief.
  5. Freeze normal routes, protected work and workload states.
  6. Use signal → acknowledge → arrival → hands-on → containment → recovery timestamps.
  7. Use visible criticality/FIFO dispatch with named ownership and waiting age.
  8. Measure Queue-Minutes, peak waiting depth, oldest age and queue-clear recovery.
  9. Account for relief debt and home-role recovery labor.
  10. Apply the Time-of-Shift Robustness Gate across fixed shift blocks.
  11. Collect context-characterized 3-op baseline and Exposure Signatures.
  12. Freeze GO / HOLD / STOP criteria and shadow rescue rules.
  13. Run shadow 2-op with rescue-only third operator; log every intervention.
  14. Compare exposure-matched windows using TPMH, Effective Labor, Support Burden, Adjusted TPMH, route burden, response/queue and time-of-shift distributions.
  15. Pareto exceptions, redesign and repeat across representative A/B/C/D conditions before true 2-op.
