Latest improvement — Context-Matched Pilot Comparison

A successful 2-op exposure on a convenient or naturally short-manned shift proves only that operating context. Add a Pilot Context Card to every baseline and shadow/2-op observation so low-load conditions cannot create a false staffing conclusion.

Context: crew/shift, scheduled/actual staffing, running press-hours/cycles, plan/actual tires, product/mix proxy, alarms + hands-on abnormal minutes, major downtime, Mold/Bladder due/completed/carryover, breaks/relief, attendance and unusual conditions.
Comparison rule: compare 2-op first with the closest 3-op operating context. Build context bands from observed plant data; do not invent thresholds.
Coverage rule: naturally short-manned trials are useful early learning exposures, but representative high-demand, break, alarm-concurrency and downtime/recovery conditions must still be validated before permanent reduction.

Best current strategy

  1. Map travel; remove avoidable motion; balance zones on workload + peaks + travel.
  2. Freeze NORMAL routes and ABNORMAL dispatch/recovery rules.
  3. Protect interrupted routine work with a visible recovery queue.
  4. Verify two-deep skills and reserve real break-relief capacity.
  5. Build 30-minute Capacity Reserve + Recovery Profiles.
  6. Freeze measurement, Leader Standard Work, SIC and escalation authority.
  7. Add Pilot Context Card; collect context-characterized 3-op baseline.
  8. Shadow 2-op and compare against context-matched 3-op periods.
  9. Pareto structural-overload/support/backlog/relief exceptions and revise.
  10. Expand across underrepresented contexts and A/B/C/D crews; true 2-op only after representative gates pass.

Next action

Add the Pilot Context Card before the first pilot comparison. Populate it for one representative 3-op shift and every shadow/2-op exposure. Keep naturally short-manned trials, but label their context and do not generalize beyond it.
