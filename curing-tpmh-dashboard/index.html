Design rules

Stagger Curing breaks
Where practical, only one Curing operator should require relief at a time.
No aggregate-capacity shortcut
Mold/Bladder spare hours count only when they coincide with the needed relief window and their own due work remains protected.
Expose the failure mode
Code relief unavailable / conflicting due work separately from true two-operator workload overload.

Best current strategy

  1. Map press layout and make alarm source visible.
  2. Balance Op 1/Op 2 by occupied workload, peaks and travel.
  3. Create two-operator standardized work and task-qualified backup.
  4. Prove break relief by time interval, not spare hours.
  5. Create Pilot Acceptance Matrix + Leader Standard Work.
  6. Use point-of-use staging to reduce routine travel.
  7. Baseline → shadow 2-op → Pareto/revise → sustained rotation → true 2-op.
